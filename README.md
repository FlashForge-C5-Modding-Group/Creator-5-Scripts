# Creator-5-Scripts
Scripts for C5, including important ones that loop!

## The "scripts" folder
A folder containing scripts for loop, the safer method to fix bricking of printers by making it not possible to break the startup shell script.


# How to run scripts
Running scripts are quite easy.

## Requirements:
Root, and an SCP client

### Tutorial:
1. Download the scripts and folders to the printer into a new folder called `tweaks` (SCP client or any way to get it onto the printer, such as WinSCP or cURL if already installed)
2. Run `cd tweaks`
3. Run `chmod +xwr tweaks-c5.sh`
4. Do `./tweaks-c5.sh`

Now you've successfully ran the script. Have fun modding!
